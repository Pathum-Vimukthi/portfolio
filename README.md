# Portfolio

Scalable Next.js starter architecture for a portfolio site.

## Structure

- `src/app` for App Router routes and layout entrypoints
- `src/components` for reusable UI and layout composition
- `src/features` for future domain modules
- `src/hooks`, `src/lib`, `src/services`, `src/types`, `src/utils`, and `src/constants` for shared application code
- `src/styles` for global styling and design tokens

## Scripts

- `pnpm dev`
- `pnpm build`
- `pnpm start`
- `pnpm lint`
- `pnpm format`
- `pnpm format:check`

## Environment

Copy `.env.example` to `.env.local` and fill in the required values before connecting any services.
